# Finding MrTC

Visual novel Ren'Py tentang Masta yang harus berkeliling lab untuk menemukan Bapak TC dan mengamankan tanda tangan FRS.

## Cara Menjalankan

1. Buka Ren'Py Launcher.
2. Pilih project `FindingMrTC`.
3. Klik `Launch Project`.
4. Mulai game dari menu utama.

## Urutan Lab dan Puzzle

1. Alpro - koreksi logika flowchart
2. RPL - pilih warna tombol delete bertema earth tone
3. NETICS - tebak password nama lab yang dibalik
4. KBJ - langkah pertama memperbaiki router hang
5. KCV - pilih variasi data yang tepat untuk dataset AI
6. PKT - lanjutkan pola deret angka
7. MCI - urutan node otomasi n8n
8. GIGA - pilih strategi pencarian data paling efisien

## Sistem Ending

- `ending_tle`: bad ending saat baterai habis atau jawaban final salah
- `ending_normal`: tamat dengan jawaban final benar, tapi sempat kehilangan baterai
- `ending_true`: tamat sempurna dengan semua jawaban benar dan baterai tetap penuh

## File Penting

- [game/script.rpy](game/script.rpy) - alur cerita utama, puzzle, dan ending
- [game/screens_custom.rpy](game/screens_custom.rpy) - HUD baterai dan progress misi
- [game/audio.rpy](game/audio.rpy) - alias audio agar mudah direferensikan
